# 🐾 Play Pet Adoption Portal

A dedicated pet adoption platform built for **Play Pet Boarding** ([playpetboarding.com](https://playpetboarding.com)), located in North Bangalore (Rajanukunte & Devanahalli).

This platform connects rescued puppies and cats with loving forever families through verified pet profiles, transparent health records, and direct 1-click WhatsApp adoption inquiries.

---

## 🌟 Key Highlights

- **Tailored Human-Centered Design:** Grounded in color psychology (soft linen, forest cypress green, warm terracotta) to evoke compassion, trust, and optimism rather than generic corporate tech templates.
- **1-Click WhatsApp Inquiries:** Direct WhatsApp button on each pet profile pre-filled with the pet's name and ID (e.g. `Kaju #D01`), eliminating adoption friction.
- **Interactive Multi-Filter Catalog:** Easily filter by *All Pets*, *Puppies & Dogs*, and *Cats & Kittens*.
- **Comprehensive Pet Profile Modals:** View medical checklists (Vaccinations, Deworming, Spay/Neuter schedule), backstories, and temperament traits.
- **Smart Sticky Header:** Glides smoothly out of view when scrolling down to maximize screen estate, and glides back down on upward scroll.
- **Mobile-First Responsive Layout:** Designed and tested for mobile phones, tablets, and desktop displays.
- **Zero-Cost Cloud Deployment:** Pure static architecture ready for GitHub Pages, Cloudflare Pages, or Vercel with ₹0/month hosting fees.

## 🚀 Deployment to GitHub Pages

1. Push this repository to your GitHub account (`Kabir-Bisanal/play-pet-adoption`).
2. Go to repository **Settings** → **Pages**.
3. Under **Build and deployment**:
   - **Source:** Deploy from a branch
   - **Branch:** `main`
   - **Folder:** `/ (root)`
4. Click **Save**. The website will be live in 1–2 minutes at:  
   `https://kabir-bisanal.github.io/play-pet-adoption/`
